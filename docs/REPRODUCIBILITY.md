# Reproducibility - Module 1

## Environment used for the reported results

| Item | Value |
|---|---|
| OS | Windows 11 Pro (10.0.26200) |
| CPU | Intel Core i7-10610U, 4 cores / 8 threads; PyTorch limited to 4 threads |
| GPU | none; all training ran on CPU (`torch 2.14.1+cpu`) |
| RAM | 15.7 GB |
| Python | 3.12.10 |
| Packages | exact pins in `requirements.txt` |
| Pretrained weights | `timm/vit_small_patch16_224.augreg_in21k_ft_in1k` (Hugging Face Hub) |
| Seeds | 42 for the split, sub-sampling and linear probe; 42, 43, 44 for the CNN and ViT repeats |

On Windows with Smart App Control, the newest SciPy and pandas wheels may be blocked; the pinned versions load correctly.

## Exact commands

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu

python -m src.download_data            # ~510 MB; add --skip-radpat for ~10 MB
python -m src.preprocessing            # labels, renders, splits, data dictionary
pytest -q                              # 18 preprocessing + integrity tests

python -m src.train_baseline --dataset patch --task perf_class --model majority
python -m src.train_vit      --dataset patch --task perf_class --mode linear_probe
python -m src.train_baseline --dataset patch --task perf_class --model cnn --seed 42
python -m src.train_vit      --dataset patch --task perf_class --mode finetune --seed 42
# ...the remaining runs are listed in scripts/run_experiments.ps1 (or scripts/run_experiments.sh)
python -m src.explainability
python -m src.evaluate                 # tables, statistical tests, figures
python scripts/make_deliverables.py    # block diagram, poster, slides, Word/LaTeX report
```

To refresh the report's table of contents and export the PDF (Windows + Microsoft Word):
`powershell -File scripts\docx_to_pdf.ps1 reports\module1_report.docx`.

| Stage | Time |
|---|---|
| Preprocessing (2,051 renders + 3,000 resizes) | ~3 min |
| Linear-probe features (patch / RadPat) | ~2.5 / ~4 min |
| Compact CNN, one run | 5–10 min |
| ViT-S/16 partial fine-tune, one patch run | ~30–40 min |
| Explainability + evaluation | ~5 min |

## Determinism

The split, sub-sampling and label thresholds are deterministic given the seed. Training is seeded, but multi-threaded
PyTorch CPU kernels do not reproduce bit for bit, which is why the main comparison is reported as mean ± SD over three seeds.

## Hand-off to Module 2

`results/features/vit_finetune_patch_perf_class_s42_{train,val,test,ood}.npy` (384-d CLS embeddings of the pre-registered
seed-42 model, rows in the order of `data/processed/patch_designs.csv` within each split) are committed and are the only
artefact Module 2 uses. Module 2 records their SHA-256 hashes in `data/external/module1_vit_embeddings/provenance.json`.

## Artefacts not stored in Git

Model checkpoints (`results/checkpoints/`, ~85 MB per ViT), other cached features, raw data and resized RadPat images.
They are regenerated by the scripts.
